One mark for everything tau touches: the README, TauBar in the menu bar, the hub's screen, the necklace and the printed enclosures.

## Idea

**τ = 2π, one full turn.** The ring is the full turn: tau is always on, always coming back around. Inside it sits a lower-case τ drawn from the same line weight. In the hero, the mark stands on the stage from the poster: two neon triangles, vertical beams and a reflecting floor.

## Files

Every file is generated by [`render.py`](render.py) from one geometry, so the hero, icons and print files always agree. Edit `render.py` and run `python3 docs/brand/render.py`; don't edit the SVGs by hand.

|---|---|
| [`tau-hero.svg`](tau-hero.svg) | README and site hero, 1280×560. Animated; stops under reduced motion |
| [`tau-mark.svg`](tau-mark.svg) | Neon mark on transparent. Dark backgrounds only, 48 px and up |
| [`tau-app-icon.svg`](tau-app-icon.svg) | App icon tile (TauBar, hub screen, social). 32 px and up |

## Site theme

The public site, tau-host's app and this docs site wear a harder theme ([ADR 0013](../adr/0013-hosted-taus-handles-and-public-pages.md) §8) built from the palette above: Void with a faint grid and a dark-blue code texture, Signal as the one accent, Ember for links and heat, Core-white type, 1 px lines and square or chamfered corners (the top-left and bottom-right corners cut at 45°). The landing page and the universe page carry the hero's motifs around the live graph: two neon triangles on a reflecting floor, faint vertical beams, instrument rings, the thinking comet and small HUD readouts. The tokens live in `cloud/shared/theme.css`; `docs/stylesheets/brand.css` repeats the ones the docs need.

| Token | Hex | Use |
|---|---|---|
| `--bg` | `#05071A` | Page background (Void) |
| `--bg-2` · `--bg-3` | `#0A0D24` · `#10142F` | Panels, cards, code |
| `--line` · `--line-2` | `#1B2042` · `#2D335C` | Hairlines; edges you can act on |
| `--text` | `#F3EEE6` | Core-white type |
| `--muted` | `#979BB9` | Secondary text |
| `--accent` | `#FF2E63` | Signal, the one accent: primary buttons, lit states, HUD rings |
| `--accent-hot` | `#FF7A3D` | Ember: links, hover, heat |
| `--accent-glow` | `rgba(255, 46, 99, .45)` | The accent's glow |
| `--void` · `--signal` · `--ember` · `--flare` · `--core` | the palette | The brand colours by name |
| `--fire` | Signal → Ember → Flare | Beams, floors, small triangles |

Type is hard and technical, with nothing rounded: **Chakra Petch** (500, 600; angular letters with cut corners) for headings, buttons and names, **IBM Plex Sans** for reading, and **JetBrains Mono** for HUD labels, the menu and code. The site bundles all three (from @fontsource, served by the site itself, so the pages' CSP allows no other font source); the docs site loads the same families through MkDocs Material.

The mark on these surfaces is `tau-coin.svg` drawn in Signal (`cloud/universe/scripts/sync-brand.mjs` derives `tau-coin-red.svg`). Online is a lit Signal square and offline a hollow one, so state never rests on colour alone.

**Sigils.** Every tau and sub-tau also has a generated **ember sigil**, drawn by `cloud/shared/character.ts` from its address: a sharp neon triangle, double-stroked from its hue's first colour to its second, with a flame of layered, angular tongues burning inside it on a white-hot core, and HUD accents around it. There are no faces or mascot parts.

- A **tau's** sigil is the richer one: a second triangle (nested, inverted or an echo behind it) and a partial τ ring with a comet head, instrument ticks and square fragments.
- A **sub-tau's** sigil is a smaller triangle with a single flame and no ring, burning in its tau's hue, so a tau and its sub-taus read as one family.
- The triangle is equilateral, tall, split at the apex, broken at the apex, notched or chamfered; the flame has one to three tongues and varies in height and lean, with sparks and ember fragments; a scan line and a reflecting floor come and go.
- Hues are mostly the fire family (signal red, ember orange, flare amber, infra crimson) with a minority of cold fires (ion blue, plasma violet, toxic green), about one in four, so neighbours in the graph stay apart.
- Below 34 px only the triangle, the flame and a tau's ring are drawn, with strokes kept visible; below 64 px the fine HUD details drop out.
- The flame flickers, its core pulses and a tau's ring turns slowly; all of it stops under `prefers-reduced-motion`, and an offline tau's sigil goes cold and still in the graph.

Sigils are not logos: never put one in place of the mark.

## Rules

- **Clear space:** keep one τ line width (the stroke) free on every side at minimum; twice that where you can.
- **Don't** stretch, rotate, outline, add drop shadows, recolour outside the palette, or put the neon mark on a light or busy background.
- **Small sizes:** below 24 px use the coin; below 48 px don't use the neon glow.

## Motion

The hero's motion is the vocabulary for every screen tau has (hub display, TauBar, site):

- **Breathing:** the light inside the ring pulses slowly (5 s) when tau is idle.
- **Thinking:** a comet arc with a bright head circles the ring (7 s, eased) while tau works.
- **Instrument rings:** the dial ticks turn very slowly in opposite directions (80 s / 120 s).

Motion always stops under `prefers-reduced-motion`.

## Terminal

The TUI (`tau tui`) draws the mark from the same geometry as `render.py` (the constants are
copied into `tau_tui/brand.py`), rasterised into half-block cells: each terminal cell holds two
square pixels (`▀` with the top pixel as foreground and the bottom pixel as background), so a
24-column mark is 12 rows and the 16-column phone mark is 8 rows. It is anti-aliased toward Void,
uses the palette only (Signal → Ember ring, Ember τ with a Core centre line) and, following the
small-size rule, has no glow. Below 20 rows the mark gives way to the wordmark line. The header
`τ` carries the motion vocabulary in one cell: it breathes (Ember ↔ Flare, 5 s) while the welcome
card is on screen and runs the comet (Ember → Flare → Core, 2 s) while tau works; it is static
otherwise and under `TEXTUAL_ANIMATIONS=none`. Under `TAU_TUI_ASCII=1` (terminals without the
block characters) the mark falls back to `#`, `^` and `_` in Ember only and every box border is
drawn in ASCII.

State colours for terminal UIs (TauBar and the hub screen reuse them): **ok / success = Flare**,
**error = Signal**, **rejected = Ember**, **running / pending = Core at 55 %**, **attention =
Flare**, notice = Ember. There is no green and no red: shapes double the colours (`●`/`○`,
`✓`/`✗`, `◆`).

## Physical objects

For the necklace, enclosures and the hub's case, use **`tau-mark-mono.svg`** or **`tau-coin.svg`**. Both are one filled compound path with even-odd holes (no strokes), so CAD tools and slicers can import them, scale them and extrude them directly.

| At this mark diameter | Ring line | τ line |
|---|---|---|
| 20 mm | 1.1 mm | 1.3 mm |
| 30 mm | 1.7 mm | 2.0 mm |
| 40 mm | 2.3 mm | 2.6 mm |

- With a 0.4 mm FDM nozzle, keep lines at 1.2 mm or more: the ring mark from about 22 mm, the coin from about 18 mm.
- Raised or recessed by 0.6–1.0 mm reads well on enclosures. A two-colour print (Ink body, Ember inlay) matches the palette.
- The pendant loop (bail) is not part of the mark; add it in CAD above the ring.
