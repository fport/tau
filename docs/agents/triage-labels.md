# Triage labels

The engineering skills speak in five canonical triage roles. In this repo a "label" is the value of an issue file's `Status:` line.

| Label in mattpocock/skills | Status in our tracker | Meaning |
|---|---|---|
| `needs-triage` | `needs-triage` | Maintainer needs to evaluate this issue |
| `needs-info` | `needs-info` | Waiting on a question (written under `## Comments`) |
| `ready-for-agent` | `ready-for-agent` | Fully specified, ready for an AFK agent |
| `ready-for-human` | `ready-for-human` | Needs the user: a decision, an account, or physical work |
| `wontfix` | `wontfix` | Will not be actioned |

Lifecycle statuses used in addition to the triage roles:

| Status | Meaning |
|---|---|
| `needs-hardware` | Specified, but blocked until the hardware arrives |
| `in-progress` | Being worked on |
| `done` | All acceptance criteria met |
